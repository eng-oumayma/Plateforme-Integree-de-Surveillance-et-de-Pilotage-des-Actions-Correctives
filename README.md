Objectif du projet

Le projet vise à remplacer le système actuel basé sur Excel et les documents papier par une plateforme web centralisée permettant la gestion, la planification et le suivi des activités de surveillance HSEE (Hygiène, Sécurité, Santé, Environnement et Énergie).

La solution permettra d'améliorer la traçabilité des inspections, d'automatiser le suivi des actions correctives et de fournir des indicateurs de performance en temps réel afin de réduire les risques de non-conformité.

👥 Acteurs du système
Admin HSEE
Gère les utilisateurs.
Configure les checklists.
Planifie les inspections.
Assigne les actions correctives.
Consulte les tableaux de bord.
Auditeur
Réalise les inspections.
Remplit les checklists.
Détecte les non-conformités.
Crée les actions correctives.
Valide la clôture des actions.
Pilote d’Action
Consulte les actions qui lui sont assignées.
Met à jour l’avancement des travaux.
Ajoute des commentaires et des preuves (photos, documents).
Soumet les actions pour validation.
